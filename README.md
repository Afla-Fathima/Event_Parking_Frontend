# Event Parking Reservation - Angular 19 Scaffold Only

This is a folder/configuration scaffold for the frontend repository.
Application source files are intentionally empty so the team can add code module by module.

## Angular version
Angular 19.2.x

## Install dependencies
```powershell
npm.cmd install
```

## Verify Angular CLI
```powershell
npx.cmd ng version
```

## Important for GitHub
Do not commit `node_modules/`. It is already excluded by `.gitignore`.

## Backend proxy
The included `proxy.conf.json` points `/api` to:
`http://localhost:5188`
