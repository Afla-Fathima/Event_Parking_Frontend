Angular 19 feature-based scaffold

src/app/core       -> guards, interceptors, models, services
src/app/features   -> admin/customer feature areas
src/app/shared     -> reusable components, directives, pipes, utils
src/environments   -> Angular environment files
public/images      -> static assets

All TypeScript/HTML/CSS application files are empty placeholders by request.
Angular workspace JSON/config files are included.
